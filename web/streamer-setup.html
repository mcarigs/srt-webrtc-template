Streamer Setup Guide

How to connect to the server and fix the "Black Screen" error.

Step 1: Black Box Fix

To prevent your stream from showing up as a black box on the website, you must turn off B-Frames. Open OBS, click Settings, and go to the Output tab. Change Output Mode to Advanced.

If using CPU (x264)

  • Find the Tune dropdown.
  • Change it to zerolatency.

If using GPU (NVIDIA/AMD)

  • Find Max B-frames.
  • Change the number to 0.
  • Set Tuning to Ultra Low Latency.

Step 2: Connect to the Server

Go to the Stream tab in your OBS settings.

  • Service: Custom
  • Server:
  • Replace X with a number 1-4 (X being your assigned slot: 1, 2, 3, or 4)
  • Stream Key: LEAVE BLANK! gameX essentially serves as your stream key, so leave this blank!

Click Apply, hit Start Streaming, and check the main page for your video feed!

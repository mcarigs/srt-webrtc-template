Host Setup Guide

How to capture player feeds into your main OBS broadcast.

Remember that gameX (X being a number 1-4) is essentially the streamkey, which will determine what feed each player is on.

Method 1: OBS Media Source (Recommended)

This is the primary method for the highest quality and best performance.

  • In OBS, add a new Media Source.
  • Uncheck "Local File".
  • In the Input box, paste the SRT link for the player you want to capture:






  • Pro-Tip: To ensure zero-latency, drop the Network Buffering down to 1 MB

Method 2: VLC Video Source (Backup)

If Media Source is lagging, skipping, or refusing to connect, OBS's built-in VLC player can serve as fallback.

  • In OBS, add a new VLC Video Source.
  • Look for the Playlist box and click the small + icon on the right.
  • Select Add Path/URL.
  • Paste the exact same SRT link from Method 1 (e.g., ) and click OK.
  • Set Network Caching to 1500, if you have issues making the feed appear, try changing to 2500, then 5000, then back to 1500

Method 3: Browser Source (Second Backup)

If the raw video feeds are failing entirely and you have exhausted all other options you can pull the web player directly.

  • In OBS, add a new Browser Source.
  • URL: Use these links to capture the players feed:






  • Width: 1920 | Height: 1080
  • Check the box that says "Control audio via OBS" so you can mix their game volume in your audio mixer.

Method 4: Application Capture (Last Resort)

If you have given up all hope, you can just pull up this site on your web browser.

  • In OBS, add a new Window Capture, and Application Audio Capture.
  • Select your browser for both, open and crop appropriately.

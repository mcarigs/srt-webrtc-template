Host Setup Guide

How to capture player feeds into your main OBS broadcast.

Each player is assigned a slot from game1 through game4. Use the corresponding link below to capture that player's feed.

Method 1: OBS Media Source (Recommended)

This is the primary method for the highest quality and best performance.

  • In OBS, add a new Media Source.
  • Uncheck "Local File".
  • In the Input box, paste the SRT link for the player you want to capture:






  • Pro-Tip: To ensure zero-latency, drop the Network Buffering down to 1 MB.

Method 2: VLC Video Source (Backup)

If Media Source is lagging, skipping, or refusing to connect, OBS's built-in VLC player can serve as a fallback.

  • In OBS, add a new VLC Video Source.
  • Look for the Playlist box and click the small + icon on the right.
  • Select Add Path/URL.
  • Paste the exact same SRT link from Method 1, for example:



    Then click OK.
  • Set Network Caching to 1500. If you have issues making the feed appear, try changing it to 2500, then 5000, then back to 1500.

Method 3: Application Capture (Last Resort)

If you have given up all hope, you can just pull up this site in your web browser.

  • In OBS, add a new Window Capture and Application Audio Capture.
  • Select your browser for both. Open and crop appropriately.
